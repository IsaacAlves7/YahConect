# ♻️ YahConect - App Mobile
Bot/ETL para coletar eventos de mensagens do WhatsApp (e, futuramente, de outras origens) e transformá-los em KPIs de **engajamento e comunicação** para consumir os dados via API/ dashboards de BI / People Analytics / Community Analytics. E seu App Mobile é um dashboard para a liderança acompanhar o projeto e desempenho, portanto, é o consumo da API.
